# Translations

Generated by `scripts/translate-site.mjs` after every build. One file per language,
keyed by a hash of the English fragment:

```json
"3f9a…": { "en": "Policy should not be probabilistic.", "t": "La política no debe ser probabilística." }
```

To correct a translation, edit `t`. It stays until the English source changes, at
which point the fragment gets a new hash and is translated again.

`npm run translate` builds, translates every missing fragment, and fails if any
remain untranslated. It needs `ANTHROPIC_API_KEY` in the environment. Commit the
updated JSON files with your content change.
