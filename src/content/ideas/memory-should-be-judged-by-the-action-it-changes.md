Memory benchmarks often stop at retrieval. Did the system find the relevant passage? That matters, but it is not the outcome.

The evidence still has to resolve to the right source, fit the applicable scope and time, reach the decision, and change what the system does. A retrieved fact that never affects the action is not useful memory. It is available context.

The test I want is downstream: compare the action without context to the action with it. Then inspect the path between them.
