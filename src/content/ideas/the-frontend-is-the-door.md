---
title: The frontend is the door, not the system
description: The interface may change, but the user's context, authority, tools, and work should remain coherent behind it.
date: "2026-09-25"
developed: "2025-10"
---

It is easy to confuse an AI product with the chat window through which a person reaches it. I think the interface is the front door.

The real system is the context, tools, permissions, models, workflows, and execution environments behind it. That distinction matters because the same person may enter through a desktop application, a browser, a wearable device, or something else.

The interface can change. The user's work, authority, and state should remain coherent behind it.

A good door makes the system easier to enter. It should not become the only place the system knows how to exist.
